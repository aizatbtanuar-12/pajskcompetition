# PAJSK Competitions for Primary Pupils, 2027

A parent's guide to the primary-school competitions that have earned PAJSK co-curricular marks, with timelines, fees, categories and team sizes.

Live site: https://thequad-a.netlify.app/

## Files

- `index.html` – the guide (one self-contained page)
- `PAJSK-Competitions-2027.pdf` – printable / WhatsApp-friendly copy
- `netlify.toml` – tells Netlify to publish this folder as-is (no build step)

Every push to `main` is deployed to the live site by Netlify.
